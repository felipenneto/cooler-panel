# Changelog

## 0.1.0

Primeira versão preparada para distribuição pública.

- Envio de temperatura/utilização de CPU e GPU ao painel HID AA88:8666, usando relatórios de 11 bytes.
- Leituras fornecidas pelo RTSS OverlayEditor; sem driver de sensores próprio.
- Bandeja, instância única, reconexão e inicialização opcional no login.
- Ícone próprio, botões de diagnóstico e valores simulados para teste do visor.
- Documentação de compatibilidade com o Husky Glacier HWT700PT, licença MIT e pacotes com SHA-256.
